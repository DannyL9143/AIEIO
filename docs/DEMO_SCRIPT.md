# Demo Script (3-5 Minutes)

## Objective

Show that AIEIO can objectively stress-test PA messaging, reveal operational communication risks, and improve message quality through AI-assisted revision.

## Setup (30 seconds)

- Open app on scenario selection screen.
- Confirm role as `instructor` first to show scenario creation modes.
- Mention this is an AI Red Team for messaging, not a social media simulator.

## Walkthrough

### 1) Select Scenario (30 seconds)

- Choose mode: `dataset-generated`.
- Select piracy scenario from authoritative data list and briefly highlight source metadata context.

### 2) Draft Message (45 seconds)

- Enter initial press statement drafted quickly under pressure.
- Highlight that this mirrors real operational constraints.

### 3) Run Simulation (60 seconds)

- Click evaluate.
- Show multi-audience reactions:
  - U.S. public
  - Local civilians
  - Allied governments
  - Host nation media
  - Adversary outlets
  - Internal military

### 4) Review Scorecard and Risks (45 seconds)

- Point to trust score and key risks.
- Call out one OPSEC/policy concern and one misinterpretation risk.
- Note explainability rationale behind the scores.

### 5) Apply Rewrite Recommendation (45 seconds)

- Apply system suggestion.
- Re-run evaluation.
- Show improved trust score or reduced risk indicators.

### 6) Show Custom Scenario Path (30 seconds)

- Switch to `instructor_custom` mode.
- Enter a quick custom scenario and confirm custom path remains available alongside data-driven generation.

## Closing (30 seconds)

- Reinforce value: objective, repeatable, explainable feedback.
- Reinforce credibility: scenario generation is grounded in authoritative piracy datasets.
- Emphasize rapid integration-ready architecture using APIs and JSON contracts.
- State fallback reliability (mock mode) for stable training and demonstrations.

## Judge Q&A Talking Points

- Why this is achievable in 48 hours
- How explainability avoids black-box scoring
- How modular APIs support future military integration
- How instructor mode enables repeatable scenario training
